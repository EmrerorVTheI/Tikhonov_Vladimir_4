# Tikhonov_Vladimir_4
4th project - Telegram bot (Exrat) from Tikhonov Vladimir
---------------------------------------------------------------------------------------------------------------------------
Бот Exrat позволяет смотреть актуальные курсы валют по отношению друг к другу и имеет встроенный калькулятор перевода суммы  
в одной валюте в другую. Бот создан при помощи Телеграм бота BotFather и API курса валют ExchangeRate-API  
  
Для использования бота необходимо его запустить (требуется VPN) и после этого открыть бота в Телеграме,  
ссылка: https://t.me/exchang_rat_bot . Затем, можно нажать start и увидеть все его команды  
  
Примечание: все валюты обозначаются тремя латинскими буквами, например RUB/rub - рубль, USD/usd - доллар и т.д.  
Доступные команды:  
/start - бот отправляет сообщение с описанием того, что делает бот и какие команды в нём есть  
/rate (1 валюта) (2 валюта) - бот отправляет курс 1 валюты во 2 валюте (/rate USD RUB выдает 1 USD = X RUB)  
/convert (кол-во) (1 валюта) (2 валюта) - бот отправляет сколько количество 1 валюты стоит во 2 валюте  
(/convert 100 RUB USD выдает 100.00 RUB = X USD)  
/help - бот отпраляет подробное описание всех комманд  
/supported - бот отправляет сообщение с количеством валют и основными валютами  
  
Бота можно интегрировать в группу в Телеграме
